# 🍲 Stew Stacker Addon

**Stew Stacker Addon** is a dedicated Fabric addon for **[Stack Size Adjuster](https://github.com/Rifaditya/Instant-Gratification-stack-size-adjuster)** that allows customizing stack limits for stews and soups dynamically using GameRules or configuration screens.

Part of the **Instant Gratification Collection** — mods that respect the player's time.

---

## 📖 End-User & Player Guide

For features, configuration options, and GameRule usage, see the **[Player Guide](Doc/Players/index.md)**.

## 🛠️ Developer & Building Guide

### Requirements
- **JDK 25**
- **Minecraft 26.2+**
- **Fabric Loader ≥ 0.19.1**
- **Fabric API**
- **DasikLibrary**
- **Stack Size Adjuster**

### Building from Source

```bash
git clone https://github.com/Rifaditya/Instant-Gratification-stew-stacker-addon.git
cd Instant-Gratification-stew-stacker-addon
./gradlew build
```

The output JAR will be generated in `build/libs/stew-stacker-addon-<version>.jar`.
