# Changelog

## [1.0.0+26.1.2] - 2026-10-23

### Added
- **Multi-Era Anchor Port (MC 26.1.2)**: Modern sovereign lead anchor release for Minecraft 26.1.2.
- **Custom Stack Limits for Stews & Soups**: Allows mushroom stew, rabbit stew, beetroot soup, and suspicious stew to stack up to custom limits (default: 16).
- **Dynamic GameRule Integration**: In-game synchronization via `stew-stacker-addon:stew_limit` (`range(1, Integer.MAX_VALUE)`).
- **Optional Client GUI Integration**: Full YACL and ModMenu support with server-side classloading isolation.
