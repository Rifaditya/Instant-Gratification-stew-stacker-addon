# Getting Started (Developers)

## 📋 Requirements

| Dependency | Version |
| :--- | :--- |
| Minecraft | 26.2+ |
| Fabric Loader | ≥ 0.19.1 |
| Fabric API | 0.150.1+26.2 |
| DasikLibrary | ≥ 1.8.3 |
| Stack Size Adjuster | ≥ 1.4.10+26.2 |
| Java | 25 |

## 🛠️ Building & Testing

```bash
# Clone repository
git clone https://github.com/Rifaditya/Instant-Gratification-stew-stacker-addon.git
cd Instant-Gratification-stew-stacker-addon

# Build artifact JAR
./gradlew build
```

Built JAR output path: `build/libs/stew-stacker-addon-1.0.0+26.2.jar`.
