## [1.0.0+1.21.1] - 2026-10-23

### Added
- Initial release of Stew Stacker Addon for Minecraft 1.21.1 (Java 21).
- Stack size customization for Mushroom Stew, Rabbit Stew, Beetroot Soup, and Suspicious Stew.
- Dynamic `/gamerule stew-stacker-addon:stew_limit` with real-time client container inventory synchronization.
- Seamless integration with Stack Size Adjuster 1.0.1+1.21.1.
- In-game configuration screen support via ModMenu and Dasik Library UniversalConfigScreen.
